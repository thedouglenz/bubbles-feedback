# Bubbles feedback

Bug reports and ideas for [Bubbles](https://bubbles.enginyyr.com), the macOS command center for Claude Code and Codex.

- **Found a bug?** [Report it](https://github.com/thedouglenz/bubbles-feedback/issues/new?template=bug.yml). In the app, **Help → Report a Bug…** fills in your Bubbles and macOS versions.
- **Have an idea?** [Suggest it](https://github.com/thedouglenz/bubbles-feedback/issues/new?template=idea.yml).

Please don't paste secrets, private code, or full agent transcripts. Bubbles keeps your work on your Mac, and this tracker is public.
